## 📌 项目简介

**AI Code Helper（享 · AI 编程助手）** 是一个基于大模型能力打造的开发辅助工具，  
致力于帮助开发者解决日常编码问题，提高开发效率，减少重复劳动。

支持：

- 🤖 AI 编程问答
- 🧠 Prompt 工程实践
- 🔍 RAG（检索增强生成）
- 📦 向量数据库
- 🔧 Tool Calling
- 🌐 Web 爬取能力
- ⚡ 流式对话（SSE）

👉 适用于：学习 AI + 提升开发能力 + 实战项目练手

## 🚀 快速启动

### 1️⃣ 克隆项目

```bash
git clone https://github.com/xiangxiang62/ai-code-helper.git
cd ai-code-helper
````

---

### 2️⃣ 启动后端

```bash
mvn clean install
mvn spring-boot:run
```

---

### 3️⃣ 启动前端

```bash
cd ai-code-helper-frontend
npm install
npm run dev
```

---

## 🧠 使用方式

1. 打开前端页面
2. 输入你的问题（如：写一个 Spring Boot 接口）
3. AI 自动生成代码 / 解释逻辑
4. 支持连续对话 + 上下文理解
